# Console（控制台）

命令行阅读：`twig guide console`。

Console 是 twig 的全局终端面板，用来浏览已登记的项目、任务和 Codex 会话，并进入项目或任务的 Shell。项目导航与任务终端共用 Twig 界面，tmux server 继续托管进程和分屏，不会自动创建侧边 Pane。可以从 tmux 外或另一个 Session 使用；不能在目标项目自身的 Session 中嵌套打开工作台。

## 1. 安装与打开

安装步骤见 [安装指南](installation.md)（`twig guide installation`）。在任意目录打开，不要求当前目录是 Git 仓库：

```sh
twig
twig console                # 与裸 twig 相同
twig --config ./config.toml    # 使用指定登记表
```

默认读取 `~/.twig/config.toml`。优先定位当前目录所属的已登记项目和任务，否则选择列表首项。

需要交互式终端，不能通过管道读取面板。脚本请使用 `twig ls` 或 `twig ls myapp`。

## 2. 让项目出现在面板里

面板只展示登记表中的项目，不会扫描磁盘。在左侧项目区按 `n`，填写：

1. **已有仓库路径**：支持绝对路径、`~/` 和相对路径；相对路径基于启动控制台时的目录。路径有空格时直接输入，无需额外加 Shell 引号。
2. **项目别名**：确定路径后默认填入主仓库目录名，可修改；使用字母、数字、横线或下划线，并以字母或数字开头。

路径字段会列出匹配的本地目录，按名称排序。`↑/↓` 选择，`Tab` 补全并保留末尾 `/`，可继续下钻；没有候选时 `Tab` 切到下一字段，`Shift+Tab` 始终切换字段。支持 `~/`、相对路径、空格和指向目录的符号链接；隐藏目录仅在当前目录名前缀以 `.` 开头时显示。补全只读取当前一级目录，不创建目录、不检查候选是否已初始化。读取失败显示原因，仍可手动输入。

路径字段按 `Enter` 先检查目录存在且属于非裸 Git 仓库，成功后切到别名字段并填入默认值；这一步不创建资源。完整目录优先，不会因存在子目录候选而误入下一级；输入尚未匹配完整目录时，先接受当前候选再检查。别名可以修改，也可以直接再按 `Enter` 完成登记。目录名含空格等不符合别名规则时，需手动修改。

除路径候选补全外，按 `Tab` / `Shift+Tab` 切字段；路径字段 `Enter` 确定路径，别名字段 `Enter` 提交；`Esc` 或 `Ctrl+C` 取消表单。登记不联网、不要求 remote。已初始化的仓库只补登记；未初始化的仓库会复用 `add` 的初始化流程，准备主窗口并登记。关联 Worktree 或子目录会定位到主仓库。同路径复用已有别名，别名指向其他路径时拒绝覆盖。

首次初始化要求仓库已有提交及本地 `main` 或 `master` 分支。其他起点请先在 Shell 中执行 `twig add NAME --path PATH --base BRANCH`。空目录创建和远程克隆暂不在表单中提供。

成功后自动选中项目并切换到任务区。也可以继续在 Shell 中使用 `twig add NAME --path PATH` 和 `twig ls`。

### 新建任务

选择项目，按 `Enter` 切到任务区，再按 `n`，填写：

- **任务名**：直接作为分支名，例如 `auth`、`feat/login` 或 `fix/bug`，不自动添加前缀；`main` 保留给主工作目录。
- **起点分支**：默认填入项目配置的基础分支，可改为其他已有本地分支，不会自动 fetch。

按 `Enter` 创建 Worktree、分支和任务窗口。成功后留在控制台并选中新任务，再按 `Enter` 才进入窗口。默认普通 Shell；配置了 `[tmux]` 时，创建窗口即启动指定的 Pane 命令，无需等待进入。项目与用户级配置规则见 [任务窗口](windows.md)（`twig guide windows`）。重复提交同名任务沿用 `new` 的接续规则，已有窗口不重复执行命令，不接管外部已有分支或目录。

### 执行中与失败重试

执行期间显示“正在执行”，表单暂不接受编辑或取消，避免强杀写操作留下锁。浏览查询的 2 秒超时不用于创建操作。字段或路径校验失败只显示具体原因；实际创建进程失败才提示已创建资源会保留。失败后保留输入和具体错误，修正后可再次提交；`PgUp/PgDn` 可滚动长错误。部分成功时保留资源，不自动删除回滚。

如果初始化已保存配置但后续失败，再次登记会补充登记表；缺失 Shell 窗口可在任务区按 `Enter` 准备。初始化/创建仍遵守原有归属检查和锁机制。

## 3. 看懂界面

宽终端采用 2×2 布局，左侧约 40%，右侧约 60%：

```text
┌─────────────────────┬─────────────────────────────┐
│ 项目列表            │ 当前项目的任务              │
├─────────────────────┼─────────────────────────────┤
│ 全局 Codex 监控     │ 当前任务详情                │
└─────────────────────┴─────────────────────────────┘
```

| 区域 | 展示内容 | 交互 |
| --- | --- | --- |
| 左上项目 | 项目别名、任务数量、Codex 状态摘要、异常 | Enter 切到任务列表并选中主工作目录 |
| 右上任务 | 主工作目录及已登记任务、分支、Git 状态、tmux 窗口状态、Codex 摘要 | Enter 进入所选任务的 Shell |
| 左下监控 | 按项目 → 任务 → 会话三级展示已加载会话，仅会话显示状态和标题，同组同名会话附短 ID | 只读，无焦点、选择或跳转；自动刷新 |
| 右下详情 | 当前任务的会话、模型、推理强度、更新时间、最近轮次、目录和异常 | ↑↓ 选择会话，Enter 读取最近轮次，i 展开或收起元数据，PgUp/PgDn 滚动 |

左下监控不开放拖选复制，避免选区快照冻结状态。展示范围固定，不受项目和任务选择、搜索、历史查询或详情展开影响；状态仍实时更新。默认全部展开，只展示有可见会话的项目和任务。项目、任务按组内最需关注的会话排序，同组内等待审批、等待输入和错误优先，其次是运行中和空闲；同优先级按名称或会话 ID 稳定排序。空间不足时显示「另有 N 个会话」，不自动滚动。数据仅覆盖当前连接的 Codex 服务可见且关联到已登记项目、任务的会话；失败或过期时明确标记旧状态。

`Tab` / `Shift+Tab` 只在项目、任务、右下详情之间切换焦点，跳过全局监控。右下详情随任务选择更新，多个会话时显示简短选择列表；完整 ID、来源、创建时间和父会话默认隐藏，用 `i` 展开。`PgUp/PgDn` 无需先切入详情区即可滚动。

也可使用 Vim 式两段按键：先按 `Ctrl-W`，再按 `h/j/k/l`（大小写均可）。`h` 回左侧项目；`l` 从项目进入任务；`j` 从任务进入右下详情；`k` 从详情返回任务。边界处保持原焦点，窄终端同样适用，不改变选中项。按 `Ctrl-W` 后底部显示方向提示，`Esc` 或其他非方向键取消本次前缀；该键不会同时执行其他操作。搜索、表单和帮助中不启用这组切区快捷键。

主工作目录不计入任务总数。项目和任务按名称排列；多个 Codex 会话分别列出，可通过 ID 区分。

默认隐藏 Codex 标记为 `ephemeral=true` 的临时会话，历史列表也不显示，状态统计不计入。此筛选只影响展示，不会删除或关闭会话，也不根据标题是否为空判断临时会话。

任务列表按表头对齐展示「任务、分支、Git、窗口、Codex」。任务区域不足 80 列时，每个任务显示两行，合并为「任务 / 分支」「Git / 窗口」「Codex」三列；过长内容在列内截断，不会挤乱后续列。

终端宽度不足 100 列时，上方按焦点显示项目、任务或详情页，仍用 `Tab` 切换；每页底部保留全局监控。至少需要 38 列、12 行。

底部显示操作提示、Codex 连接状态或错误信息。正常刷新时不会显示跳动的秒数。

## 4. 常用操作

### 导航页选中复制

项目、任务、会话列表及详情内容都支持左键拖选，松开后自动复制，并在右下角显示「已复制 N chars」或「已请求复制 N chars」，3 秒后消失。选区限定在起始区域的内容内，不包含边框或相邻列表；中文、组合字符和跨行选择按屏幕显示复制。

选区期间固定该区域的显示，后台查询和通知继续更新。单击其他位置、Esc、滚动或继续键盘操作会清除选区，缩放也会清除；有选区时 Esc 仅清除选区，其他快捷键保持原行为，Ctrl-C 仍退出 Console。鼠标单击不改变列表焦点或执行操作，继续使用 Tab、方向键和 Enter 导航。搜索、帮助和创建/删除表单暂不支持拖选复制。剪贴板方式与下方终端工作台一致；选择和复制不修改项目、任务或配置。

### 选择项目并进入任务

1. 在项目区用 `↑/↓` 选择项目。
2. 按 `Enter` 切换到任务区，默认选中「主工作目录」，再用上下键选择任务。
3. 按 `Enter` 进入其 Shell。

在项目区按 `Enter` 只切换焦点，并清除任务列表的搜索筛选；再按一次 `Enter` 才进入主工作目录。任务区按 `Shift+Tab` 或 `Esc` 返回项目区。进入前会重新核验配置和资源归属；窗口缺失时创建 Shell 窗口，Worktree 缺失时则报错，不自动重建代码。

进入任务后使用 Twig 自绘的终端工作台，不再跳到原生 tmux 界面。按 `Ctrl-W`，再按 `d` 返回导航，保留项目、任务选择和焦点；再按 Enter 可重新接入，已有进程持续运行。在导航中按 `q` 才退出 Console 回到原 Shell。

工作台底部显示当前窗口、Pane 和全局 Codex 状态摘要；状态采集继续运行。它不会向 Codex 发送提示词或审批，Codex 仍是你在 Pane 中手动运行的 CLI。跨项目切换时先返回导航再选项目；原项目进程继续运行。

#### 终端工作台快捷键

先按 `Ctrl-W`，再按下表的键；前缀提示中按 Esc 取消。工作台快捷键由 Twig 定义，不加载 tmux 的按键绑定和状态栏。

| 按键 | 操作 |
| --- | --- |
| `d` | 返回项目/任务导航，保留进程 |
| `s` / `v` | 左右 / 上下分屏，沿用当前 Pane 目录 |
| `o` | 切到下一个 Pane |
| `z` | 放大 / 还原当前 Pane |
| `h/j/k/l` | 向左 / 下 / 上 / 右切换 Pane |
| `r` | 重载 server 的 `~/.tmux.conf`，不动态改变 Twig 按键 |
| `n/p` | 当前项目的下一个 / 上一个窗口 |
| `Ctrl-W` | 将原始 Ctrl-W 发送给程序 |
| `?` | 保持显示操作提示 |

无需前缀的 `Alt-h/j/k/l` 向左 / 下 / 上 / 右调整分隔线，每次 3 格。

无需前缀的 `Shift-PgUp/PgDn` 浏览当前 Pane 历史；历史来自 tmux，布局变化或继续输入会返回底部。普通按键、方向键、功能键、Ctrl/Alt 组合键转发给程序；粘贴按程序当前的 bracketed paste 模式处理。`Ctrl-C` 交给程序，不退出工作台。鼠标左键点击内容或顶部标题切换 Pane，拖动分隔线调整大小，滚轮每次浏览 3 行历史。鼠标事件由 Twig 处理，尚不转发给 Vim/Codex 等 Pane 内程序。返回导航后继续启用鼠标捕获用于选中复制，退出 Console 时关闭。

在 Pane 内容区按住左键拖选，松开后自动复制，保留高亮；单击不复制，拖动分隔线仍调整布局。选区限定在起始 Pane，支持中文、组合字符和当前历史页面的跨行选择。选择期间固定该 Pane 的显示画面，后台程序继续运行；点击其他位置、按 Esc、滚动、继续键盘输入或粘贴会清除选区并恢复刷新。选区存在时 Esc 只清除选区；Ctrl-C 仍照常交给程序。缩放或切换窗口也会清除选区。复制纯文本，按屏幕行保留换行并去除行尾空格；暂不支持跨屏拖选或自动合并软换行。

本机复制使用系统剪贴板；不可用时显示原因，并请求外层终端复制。SSH 下直接使用 OSC 52；若 Twig 自身运行在外层 tmux 内，则使用该外层 tmux 的剪贴板转发。后两者取决于终端支持、权限及外层 tmux 的 `set-clipboard` 设置，右下角显示「已请求复制 N chars」，不代表剪贴板一定已更新。终端复制请求最多 100 KB，超过或写入失败会明确提示，选区保留。所有复制由 Twig 处理，不向 Codex/Vim 等 Pane 内程序发送鼠标或复制按键。复制后右下角浮动提示显示 3 秒：本机成功为「已复制 N chars」，终端请求为「已请求复制 N chars」，失败显示原因；连续复制更新提示并重新计时，不抢焦点、不清除选区。计数按实际复制文本的 Unicode 字符数（含换行，组合字符分别计数），不是字节数。

`exit` / `Ctrl-D` 按 Shell 自身语义退出，可关闭 Pane；关闭最后一个窗口时返回导航。希望保留任务环境时使用 `Ctrl-W d`。连接错误也会返回导航并显示原因，不清理后台资源，重新 Enter 可重连。停止进程仍使用显式的 `twig stop`，工作台没有强制关闭快捷键。

从目标项目自己的 tmux Session 中打开工作台会被拒绝，避免递归捕获当前终端以及改变外层窗口。请从 tmux 外或另一个 Session 运行 Twig。`twig new/open` 也使用相同工作台与嵌套保护，不切换外层 tmux 客户端；`Ctrl-W d` 返回 Console 并选中命令指定的项目与任务，随后可继续切换任务或按 q 退出。`new --no-open` 仍只准备资源、不打开界面。

当前终端前端在 Linux、tmux 3.8 上完成自动验收，使用现有 tmux 默认尺寸协调策略；同时连接多个不同尺寸客户端时，实际 Pane 尺寸可能受其他客户端影响。尚未验收 macOS、真实 SSH 断线、图像、超链接和扩展键盘协议。大量输出时合并刷新，最多约每 33 ms 发起一次变化屏幕查询，这不是帧率保证。

工作台按当前个人配置采用双线分隔，普通边框为 colour238、活动边框为 colour45，顶部显示 Pane 编号和程序名。进入窗口时会将 tmux 的窗口选项 `pane-border-status` 设为 `top`，为顶部标题保留空间；这是共享窗口设置，其他客户端也会看到这一变化。

以上是对个人配置的固定映射，不是通用 `.tmux.conf` 解析。`TERM`、`escape-time` 等 server 设置继续由 tmux 处理；终端快捷键由 Twig 处理，重载配置不会动态替换这些绑定。`allow-passthrough` 和超链接设置不代表 Twig 已支持原始转义序列透传或超链接显示。

若从另一个 tmux Session 启动 Twig，且外层也使用 Ctrl-W 前缀，外层会先处理按键。按这份配置，可用 Ctrl-W、Ctrl-W 将一个 Ctrl-W 传给 Twig，再按 d 返回导航；直接从 tmux 外启动则只需 Ctrl-W、d。

#### 与原生 tmux 前端的区别

**所有入口使用 Twig 界面，不代表原生 tmux 的全部交互能力都已覆盖。** Twig 通过 `tmux -C attach-session` 与 server 通信；这个客户端使用 Control Mode 协议，不绘制原生界面。后台进程、窗口、Pane、布局和历史仍由 tmux 管理。

| 能力 | 当前支持边界 |
| --- | --- |
| 历史与复制 | Shift-PgUp/PgDn 浏览历史；鼠标拖选后松开自动复制；尚无历史搜索或跨屏拖选 |
| 鼠标 | 支持点击切 Pane、拖动分隔线和滚轮历史；尚不向 Pane 内程序转发鼠标事件 |
| 快捷键 | 使用本节列出的固定按键；不读取用户的 tmux 按键绑定 |
| Pane 操作 | 支持分屏、方向/循环切换、放大和比例调整；尚无位置交换或布局预设入口 |
| 剪贴板 | 支持粘贴和选中复制；本机系统剪贴板，SSH 通过终端请求复制 |
| 原生 UI 与插件 | 不显示 tmux 状态栏、原生选择器、菜单和弹窗；依赖这些界面的插件不能直接沿用 |
| 兼容性与性能 | 常用输入和 Vim 已验收；真实 Codex 人工交互及高负载尚未验收，不能视为与原生前端完全等价 |

`.tmux.conf` 中的 server、Shell、历史和窗口相关设置仍可能生效；界面主题与按键绑定不会自动变成 Twig 的配置。不要把“原生界面不显示”理解为 tmux 配置全部失效。

tmux 的 copy/choose 等模式界面不会作为普通 Pane 输出直接发送给 Control Mode 客户端，因而 Twig 自行绘制选区并处理复制，不依赖原生 copy-mode。详见 [tmux Control Mode 官方说明](https://github.com/tmux/tmux/wiki/Control-Mode)。上述未支持能力不是已经承诺的功能；后续实现与验收完成后才会更新支持说明。

### 快速跳到列表首尾

在项目、任务或会话列表中，连续按两次小写 `g` 跳到顶部，按大写 `G` 跳到底部。作用于当前筛选后的列表，不改变焦点；历史会话只在已加载的结果中跳转，不自动加载下一页。单按 `g` 时底部显示提示，`Esc` 取消，其他键取消前缀并按原功能处理。搜索或表单编辑期间，`g` 和 `G` 作为普通输入字符。

### 搜索

在需要搜索的区域按 `/`，输入关键词，列表实时筛选：项目匹配别名，任务匹配名称或分支，会话匹配标题或 ID。搜索开始时输入为空，原筛选及选择暂存；按 `Enter` 确认普通搜索并保留筛选，按 `Esc` 取消输入并恢复此前筛选和选择。退出输入后再按 `Esc` 才清空当前筛选。

输入框上方同时显示匹配的命令候选：

| 命令 | 操作 |
| --- | --- |
| `/delete` | 任务区删除选中任务，默认取消，可保留分支 |
| `/new` | 项目区登记已有仓库；任务区新建任务；会话区提示先切区 |
| `/refresh` | 刷新状态及已展开的轮次 |
| `/help` | 打开帮助 |
| `/quit` | 退出控制台，保留 Shell 和任务 |

候选按已输入前缀过滤，**默认不选中任何命令**。`↑/↓` 选择候选，`Tab` 补全所选候选（未选择时补全第一项），`Enter` 执行。未选中候选时，只有完整、大小写精确匹配的关键字触发命令；例如 `/ne` 按 Enter 仍搜索 `ne`，`/new` 按 Enter 才执行新建。

输入期间不执行命令。执行命令前会恢复原筛选与项目、任务、会话选择，避免输入关键字时把目标筛掉；原快捷键仍可用。

要搜索关键字本身，使用双斜杠，例如 `//new` 搜索文本 `new`，不显示命令候选。输入 `//` 后的所有内容都作为搜索词。

输入期间 `j`、`k`、`g`、`G`、`q` 等作为普通字符；上下键用于候选选择。`Ctrl+C` 在普通浏览和搜索时退出；表单编辑时取消表单，创建执行期间等待操作结束。

### 查看 Codex 会话与轮次

选择任务后切换到右下详情区，选择会话即可查看模型、推理强度和更新时间；按 `i` 展开完整 ID、来源、创建时间及父会话等信息。部分字段可能未提供；会话创建、更新时间固定显示北京时间（UTC+8），格式为 `2026-10-19 14:32:08`，不随系统时区变化。「更新」指 Codex 会话记录的更新时间，不是面板刷新时间。

按 `Enter` 加载最近一轮的状态、时间和错误，按 `PgUp/PgDn` 滚动详情。轮次详情按需读取，按 `r` 更新，不展示完整对话正文。

选择会话不会跳转到某个 Pane，也不会恢复对话或向 Codex 发送消息。

### 查看历史

1. 选择项目及任务，按 `h` 开启历史查询。
2. 默认查询与所选工作目录完全一致的历史，每页最多 50 条。
3. 按 `n` 继续加载下一页。
4. 如果 Codex 从子目录启动，按 `a` 开启包含子目录，再按 `n` 逐页继续扫描。
5. 再按 `h` 返回已加载会话视图。

包含子目录时，扫描进度统计的是检查过的记录数，不等于匹配会话数；某页没有匹配结果时仍可能有下一页。历史和已加载会话按 ID 去重，不会在启动时自动扫描全部历史。

### 删除任务

在任务区选中任务，输入 `/delete` 并按 Enter，或直接按 `dd`，打开屏幕中央的紧凑确认弹窗，背景保留控制台。标题、正文、按钮和按键提示均居中对齐。长路径和错误区域可滚动，底部确认/取消按钮固定显示。单个 `d` 只显示待续提示，Esc 取消；其他键取消前缀后按原功能处理。搜索、表单和帮助中不启用 `dd`。主工作目录不能删除，项目区和会话区会提示切到任务区。

界面展示项目、任务、分支和 Worktree 路径。默认选中「取消」；Tab 或左右键切换到「确认删除」，Enter 执行，Esc 取消。↑↓ 或 j/k 选择「删除本地分支」或「同时删除被忽略文件」，空格切换勾选状态，切换后重新回到取消按钮；PgUp/PgDn 滚动长路径和错误。

默认删除任务窗口、Worktree（含被忽略文件）及任务记录，保留本地分支。「删除本地分支」默认不勾选，「同时删除被忽略文件」默认勾选。复用 `twig rm`，没有强制删除选项。存在未提交、未跟踪文件或窗口活动进程时拒绝删除；勾选删除本地分支后，还要求合并到项目目标，且相对本地 upstream 记录没有未推送提交。未配置 upstream 时只能验证本地合并，不代表远端已同步。保留分支时跳过合并及推送检查，其他保护仍然生效。CLI 的默认行为不变。

执行前重新核对仓库、任务分支和路径；确认期间目标发生变化时拒绝操作，请取消并重新打开确认。执行期间不允许重复提交或强制取消。失败显示原因，可能已完成部分清理，修正后可重新确认重试。成功后刷新列表并选中主工作目录，留在控制台。删除不涉及远端分支，也不调用 Codex 接口。

#### 同时删除被忽略文件

删除弹窗会列出 ignored 文件/目录，目录项代表目录内全部内容，可用 PgUp/PgDn 查看。默认勾选删除这些内容；若要保留，用 ↓ 或 j 选中「同时删除被忽略文件」，按空格关闭，此时存在 ignored 文件会阻止删除任务。切换选项总会重置为取消。该选项不限于缓存，也可能包含 `.env` 或本地数据，需先核对清单。清单变化时拒绝删除，请取消并重新打开弹窗查看。

该选项只放行 ignored 文件；未提交、未跟踪文件、活动进程及原有分支检查继续生效。CLI 对应 `twig rm PROJECT NAME --delete-ignored`，会在确认前输出 ignored 清单；不使用 `git clean` 或 `worktree remove --force`。

选项区固定显示，当前选项整行高亮，`[x]` 表示已勾选。清单和错误在独立区域滚动，不会滚走选项和确认按钮。

## 5. 状态含义

### Git 与 tmux

Git 摘要显示暂存、修改、未跟踪文件数量，或「干净」。干净不包含 ignored 文件，也不代表已合并、已推送或可安全删除。

窗口状态来自 tmux。窗口存在只说明 Shell 环境存在，不能用来判断 Codex 是否正在运行。

### Codex

| 状态 | 含义 |
| --- | --- |
| 运行中 | 服务报告会话处于活动状态 |
| 等待审批 | 需要到原 Codex 会话中处理审批 |
| 等待输入 | 需要到原 Codex 会话中提供输入 |
| 空闲 | 当前没有活动轮次，不代表任务完成 |
| 当前服务未加载 | 当前连接的服务未加载此会话，不推断其他服务状态 |
| 会话错误 | 服务报告会话错误 |
| 未知 / 状态过期 | 查询失败或结果长时间未更新，不能据旧值判断当前状态 |

最近轮次的完成、失败或中断单独展示。轮次完成不等于开发任务完成。

### 本轮完成通知

Twig 打开期间，会只读查询已关联任务的 Codex 轮次。检测到新的 `completed` 轮次后，导航和终端工作台右上角都会显示浮动通知卡片，标题为「✓ Codex 本轮已完成」，卡片内列出项目、任务和查看提示。卡片使用醒目的边框与背景，每条显示 8 秒后自动消失，多条排队；不抢键盘焦点、不需要按键关闭、不切换任务，终端输入照常传给当前程序。卡片暂时遮盖右上角内容，底部继续显示正常状态和快捷键。

其他任务的完成消息会在项目和任务列表留下 `[未读 N]`；进入对应任务终端后清除。仅选中列表行不会清除。收到完成事件时，正在查看的任务不弹卡片，也不留下未读；导航页中所有任务的新完成仍会提醒，仅选中列表行不算正在查看。工作台内 `Ctrl-W n/p` 切换窗口时按实际任务处理。

首次发现会话只建立基线，不提示已有的完成轮次。之后以轮次 ID 去重，查询失败不推断完成，重连后继续检查已观察会话；失败、中断和空闲不会触发成功通知。提示只代表本轮结束，不代表整个任务完成。

通知和未读只保存在当前 Twig 进程内，退出后不保留；不增加配置项，也不修改 Codex 配置。仅覆盖当前连接服务可见且关联到登记任务的会话，不保证发现两次采集之间创建并卸载的会话。

### 自动刷新与过期提示

- 项目和任务记录：约每 10 秒更新。
- tmux 与 Codex 状态：约每 2 秒更新。
- 当前所选项目的 Git 状态：约每 5 秒更新。
- 已关联会话的完成轮次：随 Codex 状态采集；历史列表与轮次详情按需读取。

间隔从上一轮查询完成后计算。Git 或 Codex 超过 30 秒未成功更新会显示固定的「状态过期」，查询失败立即显示异常。按 `r` 可请求刷新。

## 7. 常见问题

**没有项目或任务？**

检查 `twig ls`、是否用了其他 `--config`，以及项目是否完成初始化。面板不自动发现未登记项目，也不把任意 Git 分支当作 twig 任务。

**项目可见，但进入失败？**

查看底部错误及详情中的工作区异常。缺失目录、分支变化、资源归属错误或同名窗口冲突都需要先处理，面板不会接管其他窗口。

**Codex 不可用，但项目正常？**

这是允许的。Codex 为可选功能，需要 PATH 中的 Codex CLI 和已运行的本机 app-server，首个实测版本为 0.163.0。面板不会启动或重启服务。可在 Shell 中用 `codex --version` 和 `codex app-server daemon version` 检查，再按 `r` 重试。

**Codex 已打开，却找不到会话？**

只覆盖当前服务可见的会话；独立服务或 `codex --no-daemon` 实例不保证可见。CLI 仅停留在欢迎页、尚未创建会话时也不会出现。会话按工作目录关联，目录不属于登记项目/任务时不会列入；历史从子目录启动的会话需开启包含子目录查询。未进入 Codex 状态数据库的历史记录也可能不可见。

**面板会修改什么？**

浏览只读，不创建配置、锁或窗口，不 fetch/pull/push。提交登记/新建表单时会创建对应资源；任务区按 `Enter` 准备并进入 Shell。删除任务可通过 `/delete` 确认执行；停止及 PR/MR 操作继续使用明确的命令，见 [命令参考](commands.md)。

命令行操作的参数与默认值见 [命令参考](commands.md)（`twig guide commands`）。
